JAS PDF portable mode

While this file sits next to pdfcraft.exe, JAS PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfCraftData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move JAS PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\JasPdf and
%LOCALAPPDATA%\JasPdf) instead. If PdfCraftData can't be written (for example on a read-only
drive), JAS PDF says so and uses the per-user folders instead.
